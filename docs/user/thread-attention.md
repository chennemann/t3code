# Thread attention

The web and desktop thread lists distinguish automatic completion attention from a manual unread
marker:

- A thread that finishes after you last visited it is highlighted as **Done**.
- Choose **Mark unread** from a thread's context menu to keep it highlighted even if the thread has
  no completed turn or is still working. An otherwise-idle thread is labeled **Unread**; a live
  status such as **Working** or **Approval** remains visible instead.
- Opening an unread thread clears the manual marker. If you mark the thread that is already open,
  the marker remains until you leave and open that thread again.

Manual unread markers are stored by the web or desktop client. They do not currently synchronize
between clients and are not available in the mobile thread list.
