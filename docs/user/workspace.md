# Workspace

Workspace is an environment-local directory for one-off experiments and tasks that do not belong to a project. It appears with projects in the sidebar and thread picker, but T3 Code manages its directory automatically.

Create a thread in **Workspace** when you want an agent to work without choosing or creating a project. By default, every Workspace thread receives its own subdirectory so its files stay isolated. An explicitly selected working directory takes precedence.

Unassigned to-dos also use Workspace. Starting one creates a Workspace draft and fills its prompt from the to-do title and notes.
